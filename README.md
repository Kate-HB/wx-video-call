# 微信一键视频（WxVideoCall）

给只需要和儿女打视频的老人做的安卓小工具：桌面上放一个写着自己孩子名字的**大按钮**，点击后自动搜索联系人并发起视频通话；保留一加 Ace 5 已有可用路径，并增加其他机型的自动识别路径。

不用教怎么打开微信、怎么找联系人、怎么点加号——点那个写着名字的方块就行。

## 背景

很多老人用手机只有两个动作：看照片、跟儿女视频。微信的路径太长：

> 打开微信 → 找到联系人 → 点进去 → 点右下角「+」→ 点「视频通话」→ 再点「视频通话」

中间任何一步点错都会卡住。现有手机保持一键拨号；跨机型适配按节点或截图中的实际目标位置操作。

## 功能

- 桌面上生成大组件，直接显示联系人名字
- 组件可拖拽缩放（2×2 到 4×4），字随之变大
- 点击后自动：打开微信 → 搜索该联系人 → 进入聊天 → 发起视频通话
- 可以给多个联系人各放一个组件（爸爸、妈妈、儿子……）
- 同时保留普通桌面快捷方式（图标版）

## 原理

| 模块 | 作用 |
|---|---|
| `ShortcutHelper` | 用 `ShortcutManagerCompat.requestPinShortcut` 生成图标版快捷方式，图标上的名字由 Canvas 实时绘制 |
| `WxWidgetProvider` | 桌面小组件，`RemoteViews` 渲染名字，点击通过 `PendingIntent` 进入拨号流程 |
| `CallFlowActivity` | 透明中转页：拿到联系人名 → 传给无障碍服务 → 拉起微信 |
| `WxAccessibilityService` | 真正的执行者：完成搜索、点击联系人、点击「视频通话」 |

部分设备/微信版本可能返回空节点树。默认流程为：

- 当前已验证的一加 Ace 5（PKG110、1264×2780、560dpi、系统字体 1.0、微信 8.0.79）保留原有坐标路径，保持一键拨号体验；不将该配置套用到其他机型。
- 其他设备优先读取无障碍节点。Android 11+ 节点不可读时，使用内置离线中文/英文 OCR 识别搜索、粘贴、联系人和视频菜单，按文字实际位置点击；搜索图标和聊天加号通过形状检测定位。
- 自动识别核对联系人搜索结果和聊天标题，等待页面出现后继续。重名、无法识别或系统遮挡时停止，不向其他机型发送一加坐标。
- 手动校准仅为可选后备，日常使用不要求校准；后备路径不能确认身份时仍需人工操作。

采用 bundled ML Kit 中文模型，不要求手机安装 Google Play 服务或首次下载模型。合并清单移除 SDK 引入的网络权限，截图不上传。联系人名会写入剪贴板。


## 环境要求

- Android 8.0 及以上（`minSdk 26`）
- 已安装并登录微信
- 需要手动开启无障碍服务

## 安装

### 方式一：直接装 APK

从 [Releases](../../releases) 下载 `app-debug.apk`，传到手机安装（需允许「安装未知来源应用」）。

```bash
adb install -r app-debug.apk
```

### 方式二：源码编译

需要 JDK 17+ 和 Android SDK（API 34+）。

```bash
git clone <本仓库地址>
cd WxVideoCall
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

首次同步依赖较慢，`settings.gradle.kts` 已配置阿里云 Maven 镜像。

## 使用步骤

### 一、首次设置

1. 在 App 点「开启无障碍服务」，启用微信视频呼叫助手。受限设置按系统提示在应用详情解除，不能把某品牌菜单顺序套到所有手机。
2. 点「关闭电池优化」，并在「应用权限与后台设置」中检查自启动、后台运行；页面显示当前品牌的设置提示。
3. 输入联系人的唯一微信备注，执行「试运行（不拨号）」检查流程，然后添加桌面组件。已有可用配置无需重新校准。
4. 只有自动识别失败时，才使用可选的备用校准。Android 8–10 无无障碍截图 API，节点不可读时需使用后备。

### 二、添加联系人

6. 在 App 输入框里填微信好友的**备注名**（必须和微信里显示的完全一致）
7. 点 **「添加为大组件（可缩放）」**
8. 如果桌面弹出「添加到主屏幕」，直接确认；没弹就**长按桌面空白 → 小组件 → 找到 WxVideoCall → 拖到桌面**

### 三、日常使用

9. 点桌面上的绿色方块，自动搜索并拨出；识别失败时停止并提示，不要求每次手动确认。
10. 换人：在 App 里输入新名字，再拖一个组件出来
11. 删除：长按组件 → 移除

> 部分系统重启或清理后台后会停用无障碍，请重新开启；并非所有系统都会关闭。

## 权限说明

| 权限 | 用途 |
|---|---|
| 无障碍服务 | 自动点击微信界面完成拨号；配置里限定只监听微信包名 |
| 无障碍截图（Android 11+） | OCR 自动识别；可选校准保存局部图像；只保存在应用私有 noBackupFilesDir，可在 App 清除 |
| 无网络 / 无共享存储权限 | 不联网、不上传图像，不读写共享文件 |

组件联系人保存在本机 `SharedPreferences`；校准联系人、位置和局部图像保存在本机私有目录，不参与系统备份。

## 已知限制

- **没有任何机型兼容率保证**。其他品牌仍待真机验证；原机回归及算法测试不代表所有手机通过。
- 校准绑定设备系统版本、微信版本、屏幕尺寸、密度、字体比例、方向、主题、语言与可获取的导航模式；窗口边界变化会停止。该约束仅针对备用校准；默认 OCR 按当前截图定位，不使用校准坐标。
- Android 8–10 没有无障碍截图 API；节点不可读时需要逐步人工点选。Android 11+ 的截图也可能被系统或安全窗口拒绝，拒绝时不盲点。
- 自动 OCR 以中英文微信界面为主。图标形状、布局变化、极大字体、文字识别失败会停止自动流程；不能保证所有微信版本及设备兼容。
- 部分桌面（如 ColorOS、MIUI）不支持自动钉组件，只能手动长按添加。
- 部分系统可能关闭无障碍服务。默认需手动重新打开；原有通过 adb 授予 WRITE_SECURE_SETTINGS 的恢复逻辑仍保留，但不能假定所有设备有此权限。
- ColorOS 会在长时间闲置后冻结后台应用，务必完成「首次设置」里的耗电管理与自启动授权。
- 微信可能检测到无障碍服务并给出风险提示。
- 只能呼叫**已经是微信好友**的人，名字需要与备注一致。
- 首次点击前请确认微信已登录、网络正常。

## 常见问题

**点了组件没反应？**
先确认无障碍服务是开启状态，再检查 App 里输入的名字和微信备注是否完全一致。

**桌面不弹「添加到主屏幕」？**
系统桌面不支持自动钉组件，改用长按桌面 → 小组件 → 手动拖出。

**微信停在搜索页不动？**
先检查搜索内容和联系人是否唯一，再对该联系人重新校准。节点重试最长每步 15 秒，之后会提示人工操作或停止。

## 开发备注

日志 tag 为 `WxVideoCall`。验证命令：

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
.\scripts\Test-CallFlow.ps1 -Contact 唯一备注名
```

`dryRun` 只允许到最终视频/语音选择菜单，不执行最终拨号；不能识别菜单时报告失败，不把流程中止当成功。`stopAfter` 支持 search、longPress、input、result、more、video。

建议真机矩阵：ColorOS、HyperOS、OriginOS、One UI、原生 Android；小屏/长屏/折叠屏，默认/大字体，手势/三键导航，明暗主题及不同微信版本。分屏和旋转必须重新校准，当前窗口不一致时停止点击。

跨机型路径调试：`CallFlowActivity` 支持 `--ez forceAdaptive true --ez dryRun true`，可在已支持的手机上强制验证自动识别，不执行最终拨号。
