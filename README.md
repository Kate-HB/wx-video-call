# 微信一键视频（WxVideoCall）

给只需要和儿女打视频的老人做的安卓小工具：桌面上放一个写着自己孩子名字的**大按钮**，点一下，微信自动搜索并拨出视频通话。

不用教怎么打开微信、怎么找联系人、怎么点加号——点那个写着名字的方块就行。

## 背景

很多老人用手机只有两个动作：看照片、跟儿女视频。微信的路径太长：

> 打开微信 → 找到联系人 → 点进去 → 点右下角「+」→ 点「视频通话」→ 再点「视频通话」

中间任何一步点错都会卡住。这个 App 把整个流程压缩成**桌面上的一次点击**。

## 功能

- 桌面上生成大组件，直接显示联系人名字
- 组件可拖拽缩放（2×2 到 4×4），字随之变大
- 点击后自动：打开微信 → 搜索该联系人 → 进入聊天 → 发起视频通话
- 可以给多个联系人各放一个组件（爸爸、妈妈、儿子……）
- 同时保留普通桌面快捷方式（图标版）

## 原理

| 模块 | 作用 |
|---|---|
| `ShortcutHelper` | 用 `ShortcutManagerCompat.requestPinShortcut` 生成图标版快捷方式，图标上的名字由 Canvas 实时绘制 |
| `WxWidgetProvider` | 桌面小组件，`RemoteViews` 渲染名字，点击通过 `PendingIntent` 进入拨号流程 |
| `CallFlowActivity` | 透明中转页：拿到联系人名 → 传给无障碍服务 → 拉起微信 |
| `WxAccessibilityService` | 真正的执行者：完成搜索、点击联系人、点击「视频通话」 |

微信对无障碍节点做了屏蔽（`rootInActiveWindow` 返回空节点树），所以自动化采用**节点优先 + 固定坐标手势兜底**的方案：能读到节点时按文本匹配，读不到时用 `dispatchGesture` 点固定位置。联系人名先写入剪贴板，再粘贴进微信搜索框。

## 环境要求

- Android 8.0 及以上（`minSdk 26`）
- 已安装并登录微信
- 需要手动开启无障碍服务

## 安装

### 方式一：直接装 APK

从 [Releases](../../releases) 下载 `app-debug.apk`，传到手机安装（需允许「安装未知来源应用」）。

```bash
adb install -r app-debug.apk
```

### 方式二：源码编译

需要 JDK 17+ 和 Android SDK（API 34+）。

```bash
git clone <本仓库地址>
cd WxVideoCall
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

首次同步依赖较慢，`settings.gradle.kts` 已配置阿里云 Maven 镜像。

## 使用步骤

### 一、首次设置（顺序不能乱，以 ColorOS 为例）

1. 设置 → 应用 → 应用管理 → 搜索 `WxVideoCall` → 权限管理 → 右上角三点 → **解除所有授权限制**
2. 设置 → 应用 → 应用管理 → 搜索 `WxVideoCall` → 耗电管理 → **完全允许后台行为** → 允许
3. 设置 → 应用 → 自启动 → 搜索 `WxVideoCall` → **允许**
4. 设置 → 辅助功能 → 无障碍 → 已下载的应用 → **「微信视频呼叫助手」→ 允许**

> 第 4 步如果灰的、点不了，是前 3 步的限制还没解除。先把 1-3 做完，再回来点第 4 步。

### 二、添加联系人

5. 在 App 输入框里填微信好友的**备注名**（必须和微信里显示的完全一致）
6. 点 **「添加为大组件（可缩放）」**
7. 如果桌面弹出「添加到主屏幕」，直接确认；没弹就**长按桌面空白 → 小组件 → 找到 WxVideoCall → 拖到桌面**

### 三、日常使用

8. 点桌面上的绿色方块，微信自动发起视频通话
9. 换人：在 App 里输入新名字，再拖一个组件出来
10. 删除：长按组件 → 移除

> 手机重启后系统会关闭无障碍，需要重新做第 4 步。

## 权限说明

| 权限 | 用途 |
|---|---|
| 无障碍服务 | 自动点击微信界面完成拨号；配置里限定只监听微信包名 |
| 无网络 / 无存储 | 不联网、不读文件、不上传任何数据 |

所有联系人名字只保存在本机 `SharedPreferences` 里。

## 已知限制

- **坐标与机型、微信版本绑定**。微信改版后可能需要重新标定坐标；节点可读时不受影响。
- 部分桌面（如 ColorOS、MIUI）不支持自动钉组件，只能手动长按添加。
- **手机重启后无障碍服务会被系统关闭**（ColorOS 等 ROM 的安全策略），需要手动重新打开；无 root 无法自动恢复。
- ColorOS 会在长时间闲置后冻结后台应用，务必完成「首次设置」里的耗电管理与自启动授权。
- 微信可能检测到无障碍服务并给出风险提示。
- 只能呼叫**已经是微信好友**的人，名字需要与备注一致。
- 首次点击前请确认微信已登录、网络正常。

## 常见问题

**点了组件没反应？**
先确认无障碍服务是开启状态，再检查 App 里输入的名字和微信备注是否完全一致。

**桌面不弹「添加到主屏幕」？**
系统桌面不支持自动钉组件，改用长按桌面 → 小组件 → 手动拖出。

**微信停在搜索页不动？**
多半是微信改版导致坐标失效，属于已知限制，需要更新坐标。
